# TNBC miRNA-mRNA GNN

3-class tissue classifier (Normal / Primary / Metastatic) for Triple-Negative
Breast Cancer using joint miRNA+mRNA expression from GEO GSE45498 (235 matched
samples from 173 patients, NanoString nCounter).

## Method (what the paper reports)

- Patient-clean, tissue-stratified 184/51 split (no patient in both sets).
- 118 differentially expressed molecules (86 miRNA, 32 mRNA) via pydeseq2.
- Three tissue-specific **co-expression** networks: top-150 edges per type
  (miRNA-miRNA, mRNA-mRNA, cross-modal), hubs allowed, no per-node cap.
- Classifiers: XGBoost (expression-only baseline), multi-network 2-layer GAT,
  TabNet. GAT reported as the mean over 20 seeds.
- Network ablation (permuted / edge-removed / graph-only), edge reproducibility,
  SHAP-vs-attention feature attribution, TCGA-BRCA external transfer.

Enrichment, survival, the kNN network variant, and 1-layer GAT explorations were
removed from the study; their code and outputs are gone.

## How to run (do this)

```bash
bash run_pipeline.sh              # full pipeline, correct order, build-guarded
bash run_pipeline.sh --with-tcga  # also runs the TCGA transfer (needs internet)
```

Do NOT run notebooks out of order. The driver runs 01 -> ... -> end and calls
`scripts/verify_build.py` right after DE, which HALTS if `data/processed` is not
the 118-feature / 184-51 build. This is the guard that catches a stale/leaky
build (e.g. the superseded 146-feature build). `data/`, `models/`, and
`results/` are gitignored and are regenerated by the run.

## Environment

Python 3.10+. Key packages: torch, torch-geometric, xgboost, shap, scikit-learn,
networkx, scipy, statsmodels, pydeseq2. GPU recommended for the GAT (script 29 is
a 60-training job). See `requirements.txt`.

## Key facts

- DE thresholds: adj_p < 0.05, |log2FC| > 1.0 (miRNA) / > 0.5 (mRNA).
- Networks: top-150 per edge type; intra-modal by positive r, cross-modal by
  most-negative r; BH FDR kept as annotation. Cross-modal anti-correlations are
  weak (none survive genome-wide FDR) — that layer is near-noise.
- Patient-grouped CV everywhere via `data/processed/patient_ids.csv`.
